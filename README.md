# analytics-web

Сайт отчётов бота аналитики: https://eugendrky.github.io/analytics-web/

**Не редактируйте этот репозиторий вручную.** Он публикуется автоматически
из папки `web/` закрытого репозитория бота после каждого слияния в `main`.
Ручные изменения здесь будут перезаписаны.

- Данные и вход идут через API бота на Railway (адрес в `config.js`).
- Секретов здесь нет: токен бота и база остаются на Railway.
